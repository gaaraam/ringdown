# M4 야간 재실험 계획 (2026-11-17 18:00 ~ 2026-11-18 07:30)

종료 권한 검사(03a46ea)와 종료값 스키마 제한(8430089)이 LLM 성공률 0% 문제를 고쳤는지 확인한다. 실행기는 `scripts/m4-overnight.ts`.

## 순서

1. 파일럿: EXAONE 3.5 7.8B, gaga-seller 첫 6명, clean. 통과 조건은 목표 달성 1건 이상, 턴당 런타임 거부 1회 미만(본 실험 중단 기준과 같게. 처음엔 0.5였으나 거부 후 지시를 받아 고치는 것이 의도된 동작이라 18:40에 맞췄다), 시간 상한 도달률 30% 미만. 실패하면 본 실험을 시작하지 않는다.
2. 본 실험: 규칙 두뇌(기준선) → EXAONE → Qwen3 8B → Gemma3 12B. 각 모델은 Pack 3개 × clean, flaky × 30명 × 시드 1 = 180통화.

중요한 결과부터 돌리므로 중간에 멈춰도 앞선 모델의 결과는 남는다. 통화마다 `progress.jsonl`에 한 줄을 쓴다.

## 중단 규칙

| 규칙 | 조건 | 범위 |
|---|---|---|
| 모델 무효 | 첫 20통화 목표 달성 0건이고, 같은 통화에서 규칙 두뇌는 4건 이상 성공 | 그 모델의 남은 Pack 건너뜀 |
| 루프 | 20통화 이후 시간 상한 도달률 50% 이상 | 〃 |
| 거부 반복 | 20통화 이후 턴당 런타임 거부 1회 이상 | 〃 |
| 대체 과다 | 20통화 이후 턴의 50% 이상이 규칙 두뇌 대체 | 〃 (LLM을 재는 실험이 아니게 됨) |
| 인프라 | 최근 50요청 중 오류 20% 초과 | 전체 중단 |
| 구간 예산 | 구간 하나가 150분 초과 | 그 구간만 중단 |
| 마감 | 07:30 도달, 또는 남은 시간 40분 미만이면 새 LLM 구간을 시작하지 않음 | 전체 |

"첫 20통화 0건"을 모델 무효로 보는 근거: 페르소나 순서상 첫 20통화(10명 × 2장애)에서 규칙 두뇌는 Pack별로 4~5건 성공한다(ads 5, clinic 4, seller 5). 같은 통화에서 규칙 두뇌가 4건 이상 성공했는데 LLM이 0건이면 표본 운으로 설명하기 어렵다.
